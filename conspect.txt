.gitignore - файл в котором прописывем, что мы будет игнорировать на гите
requirement.txt - файл в котором хранятся все зависимости проекта 
*.pyc - pycache файлы которые создаются при первом запуске проекта, нужны
чтобы при последующих запусков проект запускался быстрее
mkdir - команда терминала для создания папки
touch - команда терминала для создания файла
* - позволяет импортировать из файла абсолютно все
